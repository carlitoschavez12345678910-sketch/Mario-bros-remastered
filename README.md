# SMB PSP

Port en C (PSPDEV) inspirado en Super Mario Bros. Remastered (GPLv3).

## Compilar
Sube el repositorio a GitHub: Actions compila y deja `EBOOT.PBP`
en la pestana Actions > ultimo run > Artifacts.

Para jugar: copia `EBOOT.PBP` a `ms0:/PSP/GAME/SMBPSP/` (o usa PPSSPP).

## Controles
D-pad = mover, X = saltar, START = salir.

## Importante
No subas ROMs ni assets de Nintendo.
